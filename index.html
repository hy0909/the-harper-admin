앱 내용을 고치려면 GitHub 토큰이 필요합니다. 토큰은 이 브라우저에만 저장되고 다른 곳으로 보내지 않습니다.

토큰 만드는 법
  1. github.com에 로그인한 뒤 오른쪽 위 프로필 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token 클릭. 이름은 아무거나(예: harper-admin), 만료일은 넉넉하게
  4. Repository access에서 Only select repositories → the-harper-app 선택
  5. Permissions → Repository permissions → Contents를 Read and write로
  6. 맨 아래 Generate token. 나온 문자열(github_pat_로 시작)을 위 칸에 붙여넣기

토큰은 한 번만 보여주니 안전한 곳에 보관하세요. 잃어버리면 새로 만들면 됩니다.
